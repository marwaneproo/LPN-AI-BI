# LPN AI-BI Frontend

React/Vite frontend for the LPN AI-BI product experience.

The conversation screen is connected to the current backend SQL generation path: React -> Vite `/api` proxy -> Java llm-orchestrator -> Schema RAG -> Ollama. Dashboards, forecasts, history, and admin screens still use mock data until their APIs are implemented.

## Run

```powershell
cd D:\LPN_PROJECT
docker compose up -d

cd D:\LPN_PROJECT\frontend
npm run dev
```

Open:

```text
http://127.0.0.1:5173
```

Ask a backend-friendly test question:

```text
How many orders were placed last month?
```

Expected result:

- the message can take 1-3 minutes on a cold laptop run;
- the Sources panel should list retrieved schema tables such as `C_ORDER`;
- the SQL panel should show SQL generated by the backend;
- the data panel should say SQL is not executed yet.

## Build

```powershell
npm run build
```

## Themes

The app includes three selectable themes in `Réglages`:

- `Sombre`
- `Claire`
- `Cream Coffee`

`Cream Coffee` is the new creamy brown theme inspired by black coffee mixed with milk: warm, low-glare, and easier for long sessions.

## Current Scope

Implemented:

- conversation UI connected to `/v1/generate-sql`;
- dashboard with mock KPI/chart/table data;
- forecasts page;
- history page;
- admin mock audit page;
- settings page with theme and density controls.

Not connected yet:

- SQL validator;
- SQL executor;
- real dashboard APIs;
- Keycloak/OIDC.
